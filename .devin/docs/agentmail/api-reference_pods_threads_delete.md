# Delete Thread

DELETE https://api.agentmail.to/v0/pods/{pod_id}/threads/{thread_id}

Permanently deletes a thread and all of its messages.

**CLI:**

```bash
agentmail pods threads delete --pod-id <pod_id> --thread-id <thread_id>
```

Reference: https://docs.agentmail.to/api-reference/pods/threads/delete

## Authentication

- `Authorization` header (bearer token, required)

## Servers

- `https://api.agentmail.to` (prod, default)
- `https://x402.api.agentmail.to` (prod-x402)
- `https://mpp.api.agentmail.to` (prod-mpp)
- `https://api.agentmail.eu` (eu-prod)

## Request

### Path parameters

- `pod_id` (string, required) — ID of pod.
- `thread_id` (string, required) — ID of thread.
