# Delete API Key

DELETE https://api.agentmail.to/v0/inboxes/{inbox_id}/api-keys/{api_key_id}

**CLI:**

```bash
agentmail inboxes api-keys delete --inbox-id <inbox_id> --api-key-id <api_key_id>
```

Reference: https://docs.agentmail.to/api-reference/inboxes/api-keys/delete

## Authentication

- `Authorization` header (bearer token, required)

## Servers

- `https://api.agentmail.to` (prod, default)
- `https://x402.api.agentmail.to` (prod-x402)
- `https://mpp.api.agentmail.to` (prod-mpp)
- `https://api.agentmail.eu` (eu-prod)

## Request

### Path parameters

- `inbox_id` (string, required) — The ID of the inbox.
- `api_key_id` (string, required) — ID of api key.
